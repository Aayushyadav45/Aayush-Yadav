Aayush Kumar Yadav - Portfolio

Project Structure:
- index.html: Main HTML page structure
- css/style.css: Custom CSS stylesheets, themes, and animations
- js/script.js: Interactivity (typing effect, theme switch, certificates lightbox, filters, contact form)
- assets/certificates/: Certificate images (Cisco, Aimaxa AI/ML, IBM Java, etc.)
- Resume-Aayush.pdf: Resume file linked in hero section

How to run:
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension, right-click index.html, choose "Open with Live Server" (or open index.html directly in any browser).
3. The "Download resume" button links directly to Resume-Aayush.pdf in this folder.
4. To add or update certificates, edit the CERTS list in js/script.js (add image files to assets/certificates/).
5. For direct contact-form delivery, paste a Formspree URL into FORM_ENDPOINT in js/script.js.

Note: Requires an internet connection to load Tailwind CSS and Google Fonts (Space Grotesk & Inter).
